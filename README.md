# Quest Classroom

Універсальний командний квест для різних предметів на Google Apps Script. Відокремлений від TECH LAB: вихідний репозиторій не змінюється.

## Що працює
- Власний JSON-файл завдань для кожної нової сесії; перевірка структури на сервері.
- 1–30 місій, 1–10 варіантів кейсу в кожній; випадковий кейс для команди.
- 1–20 команд по 1–10 учасників. Один телефон на команду, без ролей. Представник вводить назву та прізвища всіх учасників (кожне з нового рядка). Однакові прізвища дозволені.
- Код відновлення командного доступу видно команді та вчителю. Відновлення на новому телефоні змінює токен доступу.
- Три кроки: дослідження з джерелом → тест із однією правильною відповіддю → письмовий захист.
- Тест: 100 балів із першої спроби, 70 із другої, 40 із третьої, далі 30. Письмові роботи оцінює вчитель (0–100) лише для місій з `review: true`. Решта зберігається без автоматичної оцінки змісту.
- Панель учителя, ручна корекція балів, пауза, завершення, Excel (.xlsx) результатів і складу команд, видалення сесії.
- Дані сесій зберігаються окремими приватними файлами Google Drive, а не в GitHub.

## Перший запуск
1. Створіть окремий проєкт на https://script.google.com/.
2. Замініть вміст `Code.gs` кодом із цього репозиторію. Додайте HTML-файл **Index** і вставте `Index.html`.
3. У налаштуваннях проєкту увімкніть показ маніфесту. Скопіюйте `appsscript.json`.
4. Розгорнути → Нове розгортання → Вебдодаток. Виконання від вашого імені; доступ — для аудиторії, якій дозволяє ваш Google-акаунт. Надайте дозволи Drive.
5. Відкрийте отриману адресу `/exec`. Завантажте заповнений `questions-template.json`, виберіть кількість команд і PIN.
6. У панелі вставте адресу `/exec`, збережіть та покажіть спільне посилання/QR. Один представник кожної команди обирає вільний номер, вводить назву й прізвища учасників. Після реєстрації всіх команд можна починати гру.
7. Після зміни коду оновіть версію розгортання. Нова тема потребує лише нового файла та нової сесії — перевстановлення не потрібне.

За бажанням створюйте окремі копії проєкту Apps Script чи репозиторію для інших учителів. Копія GitHub сама по собі не створює вебдодаток Apps Script.

## Як заповнити файл
`questions-template.json` — нейтральний шаблон, замініть усі демонстраційні тексти. Файл UTF-8, звичайний JSON без коментарів. Можна попросити ChatGPT підготувати файл за цим зразком.

| Поле | Значення |
|---|---|
| `version` | Завжди 1 |
| `title` | Назва квесту |
| `rounds` | Масив місій, кількість довільна від 1 до 30 |
| `rounds[].title` | Назва місії |
| `info` | Досьє для всієї команди |
| `cases` | Кейси: `[питання, [варіанти відповідей], індекс правильної]` |
| `research` | Пошукові завдання в тому самому порядку, що й кейси |
| `justify` | Завдання письмового захисту |
| `review` | `true` — перевіряє вчитель; `false` — зберегти без оцінки й перейти далі |

**Індекс правильної відповіді починається з 0:** перша = 0, друга = 1 тощо. Кожний кейс має 2–6 варіантів. Для кожного кейсу потрібне окреме пошукове завдання. Приклад з двома місіями — `examples/demo.json`.

Поля дослідження універсальні: об’єкт, призначення/зв’язок із ситуацією, два факти, джерело. Мінімум символів відповідно: 3, 15, 20, 6; захист — 95. Це лише перевірка заповнення, а не правильності тексту.

## Межі першої версії
- Імпорт поки **JSON**, не Excel. Підтримується тест з однією правильною відповіддю; відповідність і послідовність ще не реалізовані.
- Немає прив’язки до предмета, класу, двох уроків або шести місій. Аварійні події з інформатики прибрано з універсальної версії.
- Оновлення стану приблизно кожні 12 секунд. Реальне навантаження класом і розгортання в Google ще потрібно перевірити; для великих потоків потрібне інше сховище.
- QR створює сторонній api.qrserver.com, якому передається посилання сесії. Можна користуватися самим посиланням.
- PIN — базовий захист панелі, не повноцінні облікові записи. Прізвища зберігаються у приватній папці власника проєкту й доступні в панелі лише з PIN. Загальнодоступний список входу не містить прізвищ. Застосовуйте прийняті у вашому закладі правила роботи з даними; не публікуйте заповнені звіти у GitHub.
- Папка `Quest Classroom — sessions` створиться у Drive власника. Готову сесію можна видалити з панелі; файли переміщуються в кошик. Автоматичного очищення немає.

## Перевірка
`node tests/engine.test.cjs` — тести з імітацією сервісів Apps Script: імпорт, командна реєстрація, повний цикл місій, ізоляція сесій, пауза, перевірка та видалення. Вони не замінюють перевірку реального розгортання.

## Excel-звіт
Кнопка «Завантажити Excel (.xlsx)» доступна під час гри й після завершення.
- **Результати команд:** місце, назва, склад, кількість учасників, командні бали, завершені/всі місії, стан. Однакові бали мають однакове місце.
- **Учасники:** окремий рядок на кожне введене прізвище, команда, її бали й завершені місії. Бали командні, а не індивідуальні оцінки.

Експорт виконується всередині Apps Script, без стороннього сервісу чи створення публічної таблиці. Файл завантажується на пристрій учителя. Текст зберігається текстом, а не формулами. У коді немає розподілу ролей.
